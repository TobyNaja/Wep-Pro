Responsive Layout: PC vs Mobile

PC จะแสดง 2 คอลัมน์ (Grid 1fr 1fr) และ Mobile จะเปลี่ยนเป็น 1 คอลัมน์ โดยใช้ Media Query เท่านั้น (ไม่ใช้ Bootstrap/Tailwind)

คอลัมน์ซ้าย (Content A)

ตัวอย่างเนื้อหาสำหรับฝั่งซ้าย บน PC จะอยู่ซ้าย และบน Mobile จะย้ายลงมาเรียงเป็นบล็อกเดียว

  • ใช้ CSS Grid จัดคอลัมน์
  • ใช้ @media ปรับเมื่อหน้าจอเล็ก
  • ไม่ใช้ Framework

คอลัมน์ขวา (Content B)

ตัวอย่างเนื้อหาสำหรับฝั่งขวา เมื่อเป็น Mobile จะเปลี่ยนจาก 2 คอลัมน์เป็น 1 คอลัมน์อัตโนมัติ

  • PC: grid-template-columns: 1fr 1fr
  • Mobile: grid-template-columns: 1fr
  • ปรับการแสดงผลได้ตามขนาดหน้าจอ

ส่วนเสริม (Card เพิ่มได้)

คุณสามารถเพิ่ม card ได้เรื่อย ๆ บน PC จะเรียง 2 คอลัมน์ และบน Mobile จะเรียงลงมาเป็น 1 คอลัมน์

ตัวอย่างเนื้อหาเพิ่มเติม

ลองย่อ/ขยายหน้าจอ หรือเปิด DevTools > Toggle Device Toolbar เพื่อดูการเปลี่ยนโหมด PC/Mobile
